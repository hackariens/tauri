## Need

Software:

- [task](https://taskfile.dev/)
- [nodejs](https://nodejs.org/)

## Download

```sh
git clone --recursive git@github.com:hackariens/tauri.git electron
cd electron
```

## Environnment

Edit .env with .env.example

## # Launch

``` sh
npm run build
```
